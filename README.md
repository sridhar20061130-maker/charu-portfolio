# CHARUMITHRA A — Portfolio

A distinctive one-page portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio structure/content
- `style.css` — responsive visual design, animation and layout
- `script.js` — cursor, scroll reveal, magnetic buttons and mobile navigation
- `assets/` — reserved for future profile photo or resume assets

## Run in VS Code
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Open `index.html`.
4. Install/use the VS Code Live Server extension, then click **Go Live**.

No npm, build step or framework is required.

## Deploy to Vercel
This is a static site. Import the GitHub repository into Vercel.
Framework preset: **Other**
Build command: leave empty.
Output directory: leave empty.
Root directory: `/`.

## Replace with a profile photo later
Put your photo in `assets/profile.jpg`, then add an image element to the hero card if desired.
